## Setup and run instructions:

1. install npm => `npm install`
2. add .env file and refer to the your: BASE_URL & KEYS
3. (generate prisma client => `npx prisma generate dev` )
4. migrate prisma => `npx prisma migrate `
5. Getting Started

   First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
